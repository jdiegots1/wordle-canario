# Palica Canario

Juego tipo Wordle con palabras y expresiones canarias.  
**Web:** https://www.wordlecanario.com/

---

## Requisitos

- **Node.js 22.x**
- **npm 10+**

Stack: **Create React App 5**, **React 17**, **TypeScript 4**, **TailwindCSS 3**.

## Instalación y arranque

```bash
npm ci
npm start
```

Abre `http://localhost:3000/`.

## Créditos

- Inspirado en Wordle. Adaptado al habla canaria y con UI propia.
